# AI Notes

This directory contains shareable AI-generated notes and small derived artifacts
from the joke-benefit pilot experiments. Large raw Hyak outputs and model
checkpoints are intentionally not tracked.

## Joke Benefit Pilot

- Fixed pilot findings: `joke_benefit_fixed_pilot_findings.md`
- Step/ratio sweep findings: `joke_benefit_sweep_findings.md`
- Experimental config and run size: `joke_benefit_experimental_config_and_size.md`

## Figures

- Benefit retention: `figures/joke_suffix_benefit_main.png`
- Main subliminal target frequencies: `figures/subliminal_target_frequency_bars.png`
- Full-probe subliminal target frequencies: `figures/subliminal_target_frequency_full_bars.png`

SVG versions of each figure are included alongside the PNGs.

## Data

Small CSVs used to make the figures and summarize the sweep are in `data/`.
The full raw evaluation artifacts remain under the local or Hyak output roots
named in the findings files.
